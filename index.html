Case Study 02 / UX Research

User Journey Analysis for Jakdojade.

The report analyzes the user experience from the moment a transport need appears, through choosing a connection and buying a ticket, to arriving at the destination. The material was based on four interviews with young app users.

Method: in-depth interviews Group: ages 18-22 Product: mobile app

Context

The app works best when it reduces stress during a trip.

Jakdojade is used to quickly plan a route from point A to point B, check connections, and buy a ticket. For interviewees, the most important values were speed, confidence in the city, routes without transfers, and the convenience of having the map, timetable, and ticket in one place.

User journey

The most sensitive moments happen when the user is already on the move.

1A transport need appears and the user opens the app.
2The user enters a destination, chooses a connection, and checks the map.
3The user buys a ticket, often under time pressure.
4The user monitors stops, transfers, and delays.
5The user reaches the address and ends the trip.

Pain points

Frustration comes less from missing features and more from low reliability at critical moments.

  • Ads appear when the user wants to quickly search for a connection or buy a ticket.
  • Outdated data about repairs, detours, delays, and holiday changes undermines trust in the route.
  • Manual vehicle-number entry increases stress in crowds, rush, or ticket-control situations.
  • Ticket-purchase failures are especially painful because they happen under high pressure.
  • Users notice the lack of long-term tickets and limited ticket availability in smaller cities.

Recommendations

The biggest opportunity is to reduce the number of decisions users must make under stress.

OfflineSaved routes available when the user loses signal.
RealtimeCurrent delays, detours, and automatic alternative routes.
Focus modeAn ad-free journey-in-progress mode with priority for key messages.
AutomationAutomatic vehicle-number completion and clearer fallback messages during ticket purchase.

Takeaway

Users appreciate Jakdojade's simplicity, but they expect a stronger sense of control.

The key direction is reducing stress and the number of actions performed during a trip. Better data, fewer clicks, fallback scenarios, and a calmer in-trip mode could meaningfully improve the user experience.
